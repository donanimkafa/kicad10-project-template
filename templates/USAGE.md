# A3 kapak şablonu

Bu proje KiCad 10 kullanıcı şablonundan oluşturulmuştur.

- Proje yöneticisinden `.kicad_pro` dosyasını açın.
- Paket kök şematikle birlikte bağlı alt sayfaları da içerir. Sayfalar arasında
  Şematik Editörü'nün hiyerarşi panelinden geçiş yapın.
- Şematik editöründe Page Settings / Text Variables alanlarından `BOARD_NAME`,
  `PROJECT_DESCRIPTION`, `PROJECT_CODE`, `DESIGNER`, `REVIEWER` ve `PHASE`
  değerlerini düzenleyin.
- Tarih, revizyon ve şirket bilgilerini Page Settings / Title Block'tan değiştirin.
- İçindekiler satırlarını elle düzenleyin. Satırlar alt sayfa oluşturmaz.
- PCB görsellerini ayrılan alanlara elle ekleyin.
- A2/A3/A4 çerçeveleri `sheet/` klasöründedir; kapak A3 olarak hazırlanmıştır.

Bu paket yalnızca KiCad tasarım başlangıcını içerir. GitHub Actions, Issue
formları ve üretim betikleri için
[tam depo şablonundan](https://github.com/donanimkafa/kicad10-project-template)
başlayın. KiCad şablon oluşturma işlemi bir GitHub deposu oluşturmaz.
